# michh.org

Michael Horacek’s personal website. Plain HTML and shared CSS, hosted on GitHub Pages.

## Local preview

From the project directory, run `python3 -m http.server 8000 --bind 127.0.0.1`, then open http://localhost:8000.

## Pages

- `index.html` — homepage
- `thoughts.html` — writing (empty until the first entry is published)
- `projects.html` — projects, interests, and founder background
- `me.html` — about and contact
- `styles.css` — shared responsive design

The existing page URLs are preserved. There is no build step. `CNAME` sets the custom domain to michh.org.
